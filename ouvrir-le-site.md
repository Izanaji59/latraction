# Comment ouvrir le site en local

## 🚀 Méthode 1 : Double-clic sur le fichier (Windows)

1. **Double-cliquez** sur le fichier `start-server.bat`
2. Une fenêtre s'ouvre avec le serveur
3. Ouvrez votre navigateur et allez sur : **http://localhost:8000/nettoyage-professionnel/**

## 🚀 Méthode 2 : PowerShell

1. **Clic droit** sur `start-server.ps1` → **Exécuter avec PowerShell**
2. Le serveur démarre
3. Ouvrez : **http://localhost:8000/nettoyage-professionnel/**

## 🚀 Méthode 3 : Terminal manuel

### Avec Python (si installé)
```bash
python -m http.server 8000
```

### Avec Node.js (si installé)
```bash
npx http-server -p 8000
```

Puis ouvrez : **http://localhost:8000/nettoyage-professionnel/**

## 📁 Pages disponibles

- **Page principale** : http://localhost:8000/nettoyage-professionnel/
- **Services digitaux** : http://localhost:8000/services-digitaux/
- **Graphismes** : http://localhost:8000/services-digitaux/graphismes/
- **Music** : http://localhost:8000/services-digitaux/music/
- **Fiduciaire** : http://localhost:8000/fiduciaire/

## ⚠️ Important

- **Ne fermez pas** la fenêtre du serveur tant que vous naviguez sur le site
- Pour arrêter : appuyez sur **Ctrl+C** dans la fenêtre du serveur
- Si le port 8000 est occupé, changez le numéro dans le script (ex: 8001, 8080)

## 🔧 Si ça ne fonctionne pas

1. **Vérifiez que Python est installé** :
   - Ouvrez PowerShell
   - Tapez : `python --version`
   - Si erreur, installez Python depuis python.org

2. **Ou utilisez Live Server (VS Code)** :
   - Installez l'extension "Live Server" dans VS Code
   - Clic droit sur `nettoyage-professionnel/index.html`
   - Choisissez "Open with Live Server"
