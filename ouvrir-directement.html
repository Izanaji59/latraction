🚀 Ouvrir le site LATRACTION

⚠️ Important : Pour que le site fonctionne correctement, vous devez utiliser un serveur HTTP local. Ouvrir directement les fichiers HTML ne fonctionnera pas à cause des chemins relatifs.

Méthode 1 : Script automatique (Recommandé)

Double-cliquez sur l'un de ces fichiers :

  • start-server.bat (Windows)
  • start-server.ps1 (PowerShell)

Puis ouvrez : http://localhost:8000/nettoyage-professionnel/

Méthode 2 : VS Code Live Server

  1. Installez l'extension "Live Server" dans VS Code
  2. Clic droit sur nettoyage-professionnel/index.html
  3. Choisissez "Open with Live Server"

Méthode 3 : Terminal

Ouvrez PowerShell dans ce dossier et tapez :

python -m http.server 8000

Ou si Python n'est pas installé :

npx http-server -p 8000

📁 Pages disponibles

Une fois le serveur démarré :
